## 1. Introduction

Mobile and web applications allow users to access services through smartphones and computers. A mobile application is installed on a device, while a web application runs through a browser. A Progressive Web Application (PWA) combines features of both.

The proposed online canteen system allows college students to browse food items, place orders, make payments, and receive notifications when their food is ready.

## 2. Problem Analysis

The traditional college canteen system has several problems:

- Students must stand in long queues to order food.
- Manual ordering can lead to mistakes.
- Students may not know whether food items are available.
- Cash payments can cause delays.
- Students waste time waiting for their orders.

An online ordering system can reduce these problems.

## 3. Proposed Solution

A Progressive Web Application (PWA) is suitable for the college canteen system.

### Comparison of Application Types

| Mobile Application | Web Application | PWA |
|---|---|---|
| Requires installation | Runs in a browser | Runs in a browser and can be installed |
| Platform-specific development may be needed | Works across devices | Works across supported devices |
| Can support push notifications | Notification support varies | Supports notifications on compatible devices |
| Requires app updates | Updated on the server | Updated through the web |

### Why PWA is Suitable

1. Students can access the application through a browser.
2. It can work on both mobile phones and computers.
3. Students can add it to their home screen.
4. It reduces the need to develop separate Android and iOS applications.

### Four Major Functionalities

**1. Menu Browsing:** Students can view available food items, descriptions, and prices.

**2. Online Ordering:** Students can select food items, add them to a cart, and place orders.

**3. Online Payment:** Students can pay through supported digital payment methods.

**4. Order Notifications:** Students receive notifications when their orders are ready.

## 4. Development Challenges

**1. Internet Connectivity:** Students need a reliable connection to place orders and complete payments.

**2. Payment Security:** The application must protect payment transactions and student information.

**3. Order Management:** The system must handle multiple orders and update food availability accurately.

## 5. Benefits and Challenges

### Benefits

- Reduces waiting time in canteen queues.
- Makes food ordering faster and easier.
- Supports convenient digital payments.
- Helps canteen staff manage orders efficiently.

### Challenges

- Network failures may interrupt ordering.
- Secure payment integration requires careful implementation.
- High order volumes may affect application performance.

A Progressive Web Application is a suitable solution for the college canteen ordering system. It allows students to browse menus, place orders, make payments, and receive notifications easily.

The proposed system reduces waiting time, improves order management, and makes canteen services more convenient.
