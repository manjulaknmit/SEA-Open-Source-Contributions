1. Introduction

Mobile and web applications play an important role in making daily activities easier and faster. A mobile application is software designed to run on smartphones and tablets, whereas a web application can be accessed through a web browser using the internet.

A Progressive Web Application (PWA) combines features of both mobile and web applications. It can be accessed through a browser and can also be installed on a device.

The college plans to develop an Online Canteen Food-Ordering System that allows students to view food menus, place orders, make online payments, and receive notifications when their orders are ready.

This system reduces waiting time, avoids long queues, and makes the canteen ordering process more convenient.

2. Problem Analysis

Currently, students may need to stand in long queues to order food and make payments at the college canteen.

The major problems are:

* Long waiting time during lunch breaks.
* Difficulty in checking available food items.
* Manual order management by canteen staff.
* Delays in payment and order processing.
* Lack of notifications about order status.

To overcome these problems, the college needs an online food-ordering application.

3. Comparison of Mobile, Web and PWA Applications

A. Mobile Application

A mobile application is installed directly on smartphones through an application store.

Advantages:

* Easy access through a mobile device.
* Can support push notifications.
* Provides a user-friendly interface.
* Can use device features.

Disadvantages:

* Requires installation.
* Separate development may be required for different platforms.
* Regular updates may be needed.

B. Web Application

A web application runs through a web browser and does not require installation.

Advantages:

* Accessible from different devices.
* No installation required.
* Easy to update and maintain.
* Can work across different operating systems.

Disadvantages:

* Requires an internet connection for most functionality.
* Browser compatibility may create challenges.
* Some device features may be limited.

C. Progressive Web Application (PWA)

A Progressive Web Application combines the advantages of mobile and web applications.

Advantages:

* Can be accessed through a browser.
* Can be installed on a smartphone.
* Supports push notifications on supported platforms.
* Can provide some offline functionality.
* One application can support multiple platforms.

Disadvantages:

* Some device features may have limitations.
* Browser compatibility must be considered.
* Offline functionality requires additional development.

4. Selection of Suitable Application

For the college Online Canteen Food-Ordering System, a Progressive Web Application (PWA) is the most suitable choice.

Justification

1. Students can access the application through their mobile browsers without downloading it from an application store.
2. Students can install the PWA on their smartphones for quick access.
3. It supports notifications to inform students when their orders are ready, on supported devices and browsers.
4. The college can maintain a single application for different devices.
5. It reduces development and maintenance costs compared to developing separate mobile applications.

Therefore, a PWA is a suitable and cost-effective solution for the college canteen.

5. Major Functionalities

The proposed Online Canteen Food-Ordering System includes the following functionalities:

1. Menu Display

* Displays available food items.
* Shows food names, prices and descriptions.
* Allows students to check the menu before ordering.

2. Online Food Ordering

* Students can select food items.
* Add items to the shopping cart.
* Choose the required quantity.
* Place orders through the application.

3. Online Payment

* Supports online payment through a secure payment gateway.
* Displays payment confirmation.
* Maintains payment transaction records.

4. Order Notifications

* Sends notifications when an order is accepted.
* Updates students about order preparation.
* Notifies students when their orders are ready for collection.

5. Order Management

* Canteen staff can view incoming orders.
* Staff can update order status.
* Completed orders can be marked as delivered or collected.

7. Development Challenges

The development of the Online Canteen Food-Ordering System may face the following challenges:

1. Payment Security

Online payments must be handled securely. The application should use a trusted payment gateway and protect users’ payment information.

2. Internet Connectivity

Students need a reliable internet connection to browse the menu, place orders and complete payments. Poor connectivity may interrupt the ordering process.

3. Order Management

During busy lunch hours, the canteen may receive many orders simultaneously. The system must manage multiple orders properly and avoid duplicate or incorrect orders.

8. Benefits of the Proposed System

* Reduced Waiting Time: Students can order food without standing in long queues.
* Easy Accessibility: Students can access the application through smartphones, tablets or computers.
* Improved Efficiency: Canteen staff can manage orders digitally.
* Convenient Payments: Online payment makes transactions easier.
* Real-Time Updates: Students receive notifications about order status.
* Better Management: Digital records help the canteen monitor orders and transactions.

9. Conclusion

The Online Canteen Food-Ordering System using Progressive Web Application technology provides an efficient solution to the problems faced by students and canteen staff.

A PWA is suitable because it combines the accessibility of web applications with useful features of mobile applications. It allows students to view menus, place food orders, make online payments and receive notifications.

Although challenges such as payment security, internet connectivity and order management exist, they can be addressed through proper software design and implementation.

Thus, the proposed system improves convenience, reduces waiting time and makes college canteen operations more efficient.
