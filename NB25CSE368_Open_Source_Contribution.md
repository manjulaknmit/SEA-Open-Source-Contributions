## 1. Introduction

Open-source software engineering is a process of developing software whose source code is publicly available. Developers can study, modify, improve and share the software. GitHub is a popular platform used for collaborative open-source development.

## 2. Problem Analysis

In this case study, a Library Management System does not have proper documentation explaining how users can issue and return books. This makes it difficult for users to understand the system.

The solution is to improve the documentation by contributing a new document to the open-source project.

## 3. Proposed Solution

A student can contribute to the project using GitHub.

### Step 1: Fork the Repository
The student opens the original GitHub repository and clicks the Fork button. This creates a personal copy of the project.

### Step 2: Create or Modify Documentation
The student opens the contributions folder and creates a Markdown file explaining the book issuing and returning process.

### Step 3: Commit Changes
The student saves the new file by committing the changes with a suitable commit message.

### Step 4: Submit Pull Request
The student creates a Pull Request to request the project owner to review and merge the contribution.

### Step 5: Review and Merge
The project owner checks the submitted documentation and merges it into the original repository if it is acceptable.

## 5. Benefits of Open-Source Contribution

- Improves software documentation and quality.
- Encourages teamwork and collaboration.
- Helps students gain practical development experience.
- Allows developers to share knowledge.
- Helps identify and fix software problems.

## 6. Challenges

- Understanding an existing project can be difficult.
- Contributions may require review and corrections.
- Developers must follow project guidelines.

## 7. Conclusion

Open-source software engineering encourages collaboration among developers. By forking a repository, creating documentation, committing changes and submitting a Pull Request, students can contribute to real-world software projects and improve their practical skills.
