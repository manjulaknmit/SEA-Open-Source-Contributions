## Project Description
This project proposes an online canteen food-ordering system that allows college students to browse food menus, place orders, make payments, and receive notifications when their orders are ready.

## Main Features
1. Food menu display
2. Online food ordering
3. Online payment
4. Order tracking and notifications

## Technology Approach
A Progressive Web Application (PWA) is selected because it can be accessed through a web browser, works across different devices, and can be installed on supported devices.

## Benefits
- Reduces waiting time.
- Minimizes overcrowding.
- Improves order management.
- Provides convenient food ordering.

## Conclusion
The proposed system makes college canteen services more efficient and convenient for students and canteen staff.
